# Лабораторная работа №2
## Эмпирический анализ временной сложности алгоритмов сортировки

**Студент:** Осипова Анна Алексеевна  
**Вариант:** 17  
**Дисциплина:** Теория алгоритмов

### 1. Цель работы
Освоить методику экспериментального исследования временной сложности алгоритмов и сопоставить эмпирические зависимости с теоретическими оценками на примере сортировки пузырьком и сортировки вставками.

### 2. Задание варианта
Для варианта 17 используются массивы размеров **1000, 2000, 3000, 4000, 5000**, случайные целые числа из диапазона **[0; 10]**, 3 повторения каждого замера. Дополнительно выполнено задание **М7** — сортировка записей `(фамилия клиента, сумма заказа)` и демонстрация устойчивости алгоритмов.

### 3. Теоретическая сложность
Оба алгоритма имеют сложность `Θ(n²)` в среднем и худшем случаях, а лучший случай — `Θ(n)` для реализованных версий. Дополнительная память — `O(1)` для самого алгоритма сортировки; функции возвращают копию входного массива.

### 4. Методика
Для измерения использован `time.perf_counter()`. Для обоих алгоритмов на каждом размере использовалась одна и та же сгенерированная последовательность, а итоговым значением принималась медиана трёх измерений. Корректность проверялась сравнением с `sorted()`.

### 6. Проверка квадратичного роста

Для проверки использовано отношение `T(n)/n²`. При квадратичной зависимости это отношение должно оставаться примерно одного порядка величины. Незначительные колебания объясняются особенностями среды выполнения, кэшированием и работой операционной системы.

### 7. Дополнительное задание М7

Использованы записи:

`(Иванов, 1200), (Петров, 800), (Сидоров, 1200), (Кузнецов, 500), (Смирнов, 800), (Попова, 1200)`.

После сортировки по сумме порядок записей с одинаковой суммой сохраняется:
- 800: Петров → Смирнов;
- 1200: Иванов → Сидоров → Попова.

Это демонстрирует устойчивость обеих реализованных сортировок.

### 8. Вывод
Эксперимент позволяет сопоставить практическое время работы двух квадратичных алгоритмов с теоретической оценкой `Θ(n²)`. Для варианта 17 использованы данные с большим числом повторяющихся значений. Дополнительная проверка показала сохранение относительного порядка записей с одинаковым ключом сортировки.
