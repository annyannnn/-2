## Задание варианта

- Размеры массива: `1000, 2000, 3000, 4000, 5000`
- Тип данных: `D` — случайные целые числа с большим числом повторов
- Диапазон: `[0; 10]`
- Число повторов каждого измерения: `3`
- Дополнительное задание: `М7`

Основные алгоритмы:
1. Сортировка пузырьком с флагом `swapped`.
2. Сортировка вставками.

М7:
- сортировка записей `(фамилия_клиента, сумма_заказа)` по сумме заказа;
- демонстрация устойчивости обеих сортировок.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

После запуска создаются:
- `results.csv` — результаты измерений;
- `lr2_plot.png` — график времени;
- `system_info.txt` — характеристики среды выполнения.

## Важно

Абсолютное время зависит от компьютера и версии Python. Поэтому результаты `results.csv` генерируются непосредственно на машине, где запускается лабораторная работа.
