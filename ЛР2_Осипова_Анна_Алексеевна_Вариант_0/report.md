## Цель
Освоить экспериментальное исследование временной сложности алгоритмов сортировки.

## Задание
Исследовать пузырьковую сортировку и сортировку вставками на случайных целых числах `[0; 100000]` для `n = 500, 1000, 2000, 3000, 4000, 5000`. Каждый замер повторяется 3 раза, берётся медиана.

## Теория
Оба алгоритма имеют `Theta(n^2)` в среднем и худшем случае, `Theta(n)` в лучшем случае и `O(1)` дополнительной памяти. Сортировки устойчивы.

## Блок-схема пузырька
```mermaid
flowchart TD
A([Начало])-->B[Копия массива]-->C[i=0]-->D{i<n-1?}
D--Нет-->Z([Конец])
D--Да-->E[swapped=False]-->F[j=0]-->G{j<n-1-i?}
G--Нет-->H{swapped?}
H--Нет-->Z
H--Да-->I[i=i+1]-->D
G--Да-->J{A[j]>A[j+1]?}
J--Да-->K[Обмен; swapped=True]-->L[j=j+1]-->G
J--Нет-->L
```

## Блок-схема вставок
```mermaid
flowchart TD
A([Начало])-->B[Копия массива]-->C[i=1]-->D{i<n?}
D--Нет-->Z([Конец])
D--Да-->E[key=A[i]; j=i-1]-->F{j>=0 и A[j]>key?}
F--Да-->G[A[j+1]=A[j]; j=j-1]-->F
F--Нет-->H[A[j+1]=key; i=i+1]-->D
```
