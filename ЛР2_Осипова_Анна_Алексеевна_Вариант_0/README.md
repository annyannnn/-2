## Задание
Сравнить сортировку пузырьком с флагом и сортировку вставками на случайных целочисленных массивах `[0; 100000]`.

Размеры: `500, 1000, 2000, 3000, 4000, 5000`. Повторов: `3`, итог — медиана.

## Запуск
```bash
pip install -r requirements.txt
python lr2.py
```

После запуска создаются `results.csv`, `results.txt` и `lr2_plot.png`.

## Сложность
Оба алгоритма имеют `Theta(n^2)` в среднем и худшем случае и `Theta(n)` в лучшем случае.
